---- users ---- tabela de usuários
id - identificador único do usuário
email - e-mail de login (único)
name - nome exibido na interface
password_hash - senha criptografada
is_active - se a conta está ativa (false = bloqueado)
created_at - data de criação da conta
created_by - usuário que criou esta conta (admin)
is_admin - administrador (preços, usuários, operação)
is_master_admin - administrador master (acesso total, inclusive outros admins)

---- pricing_config_versions ---- tabela de versões da configuração de preços
id - identificador desta versão
prices_json - catálogo completo de preços (preço base mensal, serviços, relatórios, adicionais, faixas)
created_at - data de criação do registro
created_by - usuário que cadastrou o registro

---- clients ---- tabela de clientes
id - identificador do cliente
name - nome do cliente
is_active - se o cliente está ativo
created_by - usuário que cadastrou o cliente
created_at - data de cadastro

---- proposals ---- tabela de propostas
id - identificador da proposta
status - situação (rascunho, enviada, aprovada, expirada)
client_id - vínculo com cliente cadastrado (pode ser vazio)
name - título da proposta
content_json - JSON (escolhas: escopo, serviços ligados, volumes, relatórios, adicionais; sem preços)
pricing_config_version_id - referência à versão de preços; todos os preços dos serviços vêm desta tabela
created_at - data de criação
updated_at - data da última alteração
created_by - usuário que criou
updated_by - usuário que alterou por último

Notas (proposals.content_json):
  - sem objeto "prices"; preços vêm de pricing_config_versions via pricing_config_version_id
  - clientName: quando client_id for vazio; com client_id pode omitir ou espelhar clients.name
  - proposals.name (coluna) = título; clientName = nome do cliente no wizard/HTML
  - assessmentTierId, socialMediaTierId, etc. = ids das faixas em prices_json da mesma versão
  - globalBillingMode: "fixed" | "variable" (toggle do resumo)
  - radioRegion / tvRegion: "spRj" | "national" quando o adicional estiver ligado
  - executiveFrequency / strategicFrequency: weekly | biweekly | monthly | quarterly | semiannual | annual
  - baseMonthlyPrice: preço base desta proposta (lê default de prices_json.baseMonthlyPrice)
  - currentStep: etapa do wizard (0 a 4); opcional em rascunho
  - registros legados em português são migrados automaticamente pelo app ao carregar
